function degistir() {
  const yeni = !kapali;

  if (
    yeni &&
    !window.confirm(
      "Site bakıma alınsın mı? Admin dışındaki tüm roller..."
    )
  ) return;

  startTransition(async () => {
    const r = await siteKapaliDegistir(yeni);
    if (r.error) return setMesaj(`Hata: ${r.error}`);

    setKapali(yeni);
    router.refresh();
  });
}

Server-action authorization
All admin settings actions use requireAdmin() in [src/app/yonetici/actions.ts (line 24)](E:/SG_EDUCOACH/src/app/yonetici/actions.ts:24):
async function requireAdmin() {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();

  if (!user) redirect("/yonetici");

  const { data: profile } = await supabase
    .from("profiles")
    .select("role")
    .eq("id", user.id)
    .single();

  if (profile?.role !== "admin") redirect("/");

  return {
    supabase,
    user,
    admin: createAdminClient(),
  };
}
The code verifies the authenticated role before creating and using the service-role Supabase client. Successful mutations are generally recorded in admin_audit_log.

Detailed path:

6. For /, /dashboard, /moderator, /login, and /signup, a closed site rewrites non-admin traffic to /site-bakimda.
